Image Gallery

A simple website to exhibit the photos I take

There have been 3 major phases the website has been through.


Phase one

The initial implementation of it consisted of a Golang backend with a HTMX frontend. This was my first attempt at creating a webapp so it was extremely difficult to fix and update


Phase two

Had recently learned React for the CRISiSLab Meshtastic network monitoring and management system. The combination of weird page history caused by my use of htmx and my spaghetti backend code's maintainability I decided to refactor my backend code and create a React frontend for the website. This was satisfactory until I started film photography and realized my website could only store data useful for digital photography. This would require alot of work to update the code that handled data storage. I had been tinkering with SpringBoot and found JPA to be very easy. So I migrated my backend to SpringBoot.


Phase three (current state)

The backend is currently now in SpringBoot. Additionally users do not need a login to view images.
